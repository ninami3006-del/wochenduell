# Wochenduell

Fitness-Challenge unter Freunden: Punkte für Schritte, verbrannte Kalorien, Workouts und das eigene Kalorienziel. Jede Woche gibt es einen Sieger.

- `docs/` ist die Web-App, die GitHub Pages ausliefert. Sie lässt sich auf dem iPhone über Safari → Teilen → „Zum Home-Bildschirm“ als App ablegen.
- `wochenduell.html` ist der ursprüngliche klickbare Prototyp.

Aktuell zeigt die App noch Beispieldaten. Echte Werte aus Apple Health und Whoop kommen in einem späteren Schritt dazu.
